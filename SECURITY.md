# Security

Please report a vulnerability in the Flung MCP server, the API or the SDK privately, through **Security → Report a vulnerability** on this repository (GitHub private vulnerability reporting). Do not open a public issue.

Say what you found, how to reproduce it, and what it lets someone do. We reply within three working days and tell you when it is fixed.

Please do not test against accounts that are not yours, run automated scans that send large volumes of requests, or try to reach other people's data.
